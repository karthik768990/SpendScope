# SpendScope

## Summary
SpendScope is an AI infrastructure audit tool that helps startups identify overspending on AI tools like GitHub Copilot, Cursor, ChatGPT, Claude, etc., and provides actionable recommendations to downgrade, switch, or consolidate plans.

## Decisions
- Used Next.js App Router for optimal performance and SEO.
- Used Supabase for backend to quickly capture leads without complex auth.
- Tailwind CSS and shadcn/ui for fast, beautiful UI components.
- Resend for transactional emails.
- Anthropic API for generating personalized recommendations.
